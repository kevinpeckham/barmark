# barmark

Markdown-inspired plain-text notation for chord charts — the bar grid
musicians already write (`| D | A |`), specified precisely enough for
machines.

This package currently reserves the name while the spec and reference
parser are written. The grammar draft (v0.1, for review) is
[docs/grammar-v0.1-draft.md](https://github.com/kevinpeckham/barmark/blob/main/docs/grammar-v0.1-draft.md);
the founding brief, prior art and roadmap live in
[BRIEF.md](https://github.com/kevinpeckham/barmark/blob/main/BRIEF.md).

A barmark file is a markdown file: the extension is `.chart.md`.
