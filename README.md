# barmark

Markdown-inspired plain-text notation for chord charts — the bar grid
musicians already write (`| D | A |`), specified precisely enough for
machines.

This package currently reserves the name while the spec and reference
parser are extracted from production code. The grammar draft, prior
art, and roadmap live in [BRIEF.md](./BRIEF.md).

A barmark file is a markdown file: the extension is `.chart.md`.
