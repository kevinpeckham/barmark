package uses [semantic versioning](https://semver.org/).

## [Unreleased]

### Added

- The package: a barmark chart exported as a lyric sheet in ChordPro's text format, and what the export could not carry. It needs `barmark` and `@barmark/fretboard`; ChordPro is a separate project that this package only writes for.
- **`exportLyricsheet(chart, options?)`** answers `{ ok: true, text, diagnostics, losses }` or `{ ok: false, diagnostics }` and never throws. Options: `part` (the part's label), `title` (for a chart with none) and `diagrams: "guitar"`. Types: `LyricsheetOptions`, `LyricsheetResult`, `LyricsheetLoss`, `LyricsheetLossCode`; `VERSION`.
- **`diagrams: "guitar"`**: a `{define: Am base-fret 1 frets x 0 2 2 1 0}` line for every chord name the sheet writes (lyric lines and grid cells), once each in the order first written, in a block between the header and the first section, from `@barmark/fretboard`'s shapes. Frets are counted from `base-fret`, and a shape that reaches the fifth fret starts at its lowest fretted one, since a diagram is four frets tall. A voicing written after a chord is the name's shape when every use of the name writes that one voicing and a hand can play it; otherwise the name's own shape is written (`voicing` loss). A chord with no shape gets none (`no-shape` loss); an altered chord is a shell (`shell-shape` loss). A chord name ChordPro's parser rejects that is defined is no longer a `chord-names` loss. Without `diagrams` the output is unchanged.
- Losses: `key-mode`, `other-parts`, `other-lines`, `stacked-verses`, `chord-moved`, `text-changed`, `chord-names`, `note-sets`, `voicing`, `marks`, `bar-meter`, `fermata`, `mark-moved`, `no-shape` and `shell-shape`, each reported once, at its lowest bar.
- Checked by golden sheets for every fixture chart, with and without diagrams; a played yardstick that reads each sheet back into chords and words in play order; ChordPro's own `chordpro --strict` on every golden, on the maintainer's machine only; scale tests (a 1,000-bar chart in linear time, 2,000 distinct chord names with diagrams); and every chart of the corpus, with and without diagrams.
- `exportLyricsheet`: refuses a chart with errors, an unknown part or no bars, and writes the song's header (title, credits, key, time and tempo) as ChordPro directives; a sheet always has a title line (the chart's, else `title`, else `{title: }`).
- Sung sections as ChordPro lyric environments, in play order: each chord before the syllable it lands on, a chord on no syllable standing alone, `{chorus}` for a replayed chorus singing the same words, annotations for `N.C.`, stops, `?`, note sets, words, rehearsal marks and fermatas, key, time and tempo changes where they happen (each with a comment a reader sees), a repeat singing the same words again kept in one environment, and comments for text lines, rit., accel. and feel. One part's harmony (the one named, else the first that writes chord symbols) and the singer's words. Losses: `other-parts`, `other-lines`, `stacked-verses`, `chord-moved`, `text-changed`, `chord-names`, `note-sets`, `voicing`, `marks`, `bar-meter` and `fermata`.
- Sections with no words as ChordPro grids (`{start_of_grid: label="Intro" shape="1+4x4+1"}`), so a chart with no lyrics loses almost nothing: a cell per beat of the bar's own meter (6/8 two, 12/8 four), `.` for a beat held, `/` for a name played again, `C~G` for chords sharing a beat, `%` where the chart wrote it, `N.C.`, `*Stop`, `*?` and a note set's notes (`*C,E,G`) as cells, a fermata as a measure of its own (`*…`), words as right-margin text and rehearsal marks as left-margin text. An occurrence that plays its written lines straight through keeps `|:`, `:|`, voltas `|1` `|2` and `x N`; any other (cut by a jump or `->`, a heading's `x N`, an ending for several passes) is written as played. An open repeat is followed by `{comment: repeat ad lib.}`. Key, time, tempo and feel changes and text lines inside a section with no words are written there too.
- Grids never build more bars than the chart plays, however large a count after a jump (`x 999999999`), and each line's bar cells are read once; no written line ends in a backslash (a final `\` is written `/`) and a tab is written as a space; a heading's backslash-n stays one label line; a rehearsal mark starts its own grid line (a line with `x N` keeps it at its start, the new `mark-moved` loss); margin words that read as a count are quoted (`"x3"`); `%` only where it plays the measure before it (not after a time change or a fermata, nor first in a line); a stacked verse that sings nothing writes nothing; a grid's shape is its widest line's, so an occurrence is one grid and `{comment: repeat ad lib.}` sits inside it.
