# MusicXML 4.0 schema (tests only)

`musicxml.xsd`, `xlink.xsd` and `xml.xsd` from
<https://github.com/w3c/musicxml/tree/v4.0/schema>, published by the W3C
Music Notation Community Group under the W3C Community Final
Specification Agreement (see the notice in `musicxml.xsd`). One change:
`musicxml.xsd` imports `xml.xsd` and `xlink.xsd` from this folder instead
of from musicxml.org, so validation works offline. Not published with the
package.
