# @barmark/midi

MIDI for [barmark](https://barmark.dev) chord charts: export a chart's
play order as a Standard MIDI File, and (later) import one as a chart.
The performance core, chart to timed notes, is the `@barmark/midi/perform`
subpath.

```sh
npm install @barmark/midi
```

Work in progress: nothing is exported yet.
